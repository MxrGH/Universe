# Universe

Universe is a Geometry Dash 2.2091 Geode utility and local-practice toolkit by MxrMC.

The project includes an in-game tabbed panel, practice utilities, visual helpers, StartPos tools, and a local input recorder/replay prototype. Some source features still require in-game testing and are not represented as verified releases.

## Upcoming

- AI Level Maker: prompt-based editable level drafts.
- Eclipse-inspired panel expansion: trajectory display, more visual/player controls, UI themes, expanded replay tools, and improved mobile access.

## Fair-play behavior

Safe Mode only changes local game state. It is not a guarantee of server-side leaderboard enforcement. Online unlocks, achievements, verification, coins, and leaderboard results are not spoofed.

## Build target

- Geometry Dash: 2.2091 (Windows and Android)
- Geode: v6.0.0-alpha.1
