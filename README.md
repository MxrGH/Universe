# Universe

A Geode mod project for Geometry Dash **2.2091** (Windows), maintained in [MxrGH/Universe](https://github.com/MxrGH/Universe).

## Current project status

- Geode project metadata and Windows build workflow are present.
- A Universe entry button is present in the main menu.
- Safe Mode, click-sound, noclip, local icon-preview, and practice-tool settings are declared.
- The actual gameplay hooks and custom control panel are still under development.
- The supplied click sound is not yet included in the packaged resources.

Safe Mode is intended to keep modified gameplay from being submitted as legitimate records. Icon previews and testing features are local-only; the project will not spoof server-side data or fabricate online achievements.
